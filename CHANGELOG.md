# Changelog

## Unreleased

- A task's Add Link… opens a link field in the row, so the link becomes the task's action instead of a saved link. Typing a task with a URL in it still works too.

## 1.0 (November 2026)

The first release.

- Tasks, notes and links in one panel, grouped into Spaces, opened with ⌃Space.
- Capture in one line: `#space`, dates like `tomorrow` or `fri`, `!` for important, `every monday` to repeat, and links that keep their titles.
- ⌃⌥S saves the tab you are on in Dia, Arc, Chrome, Brave, Edge or Safari.
- A companion on the edge of the screen, Perched or On the cord, in four plumages. Perched comes in four sizes, from Mini to Large.
- Search across everything, Markdown notes, reminders, Recently Deleted for 30 days.
- Daily backups, and Export and Import as JSON with a Markdown copy.
- Check for Updates opens the releases page. Remi itself never contacts a server about versions.
